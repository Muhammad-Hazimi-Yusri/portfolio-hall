# Combined portfolio release — 26 September 2026

The owner explicitly requested merging and pushing the current work to the
deployed app. This releases the accumulated hall, project, professional-content,
navigation and performance changes in one PR. It does not mark the broader
visual-polish goal or the pending acceptance checks complete.

The existing release target is GitHub Pages at
https://new.muhammadhazimiyusri.uk/, through the push-to-main deployment workflow.
No domain migration or visitor-service deployment is part of this release.
The unconfigured visitor service stays offline, with public writes disabled.

## Publication adjustment

The S3A dataset access terms at
https://cvssp.org/data/s3a/public/audio_visual_register.php prohibit redistribution.
The listening-room mesh, class data and reference panorama have therefore moved
from the public directory into ignored `_local/avvr-archive/` storage. Their local
integrity checks still pass. The archive renderer is disabled in this release,
and the island opens the original spatial-audio illustration instead. Original
project notes and the application screenshot remain available. The portfolio
build check rejects these restricted dataset files in both public and dist.

Earlier archive reviews document local research views, not this release's public
presentation. Worker briefs and unrelated evaluation files are not included.
