Only the 257 two-letter SVG filenames and the license were copied. The SVGs
are unchanged; `manifest.json` records each SHA256. Total SVG size: 1,700,059
bytes. No package scripts, CSS, dependencies or runtime library are installed.

The hall loads only flags present in its bounded recent-visitor list (at most
12), from its own origin, then paints one shared atlas. No flag requests are
made when the visitor service is disabled. An unknown country keeps a neutral
dash; an unavailable flag retains its country code. Local preview records are
not assigned invented countries to make the display more colourful.
